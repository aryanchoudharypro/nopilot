# copilot-to-right-ctrl

Turns the Copilot key on Windows laptops back into a real Right Ctrl key.

It is a single small native executable with no dependencies, no window and no tray icon. It installs a low-level keyboard hook and nothing else.

## Why

On many recent laptops the Right Ctrl key was replaced by a Copilot key. That key has no key code of its own: the keyboard sends `Left Windows + Left Shift + F23`. This tool swallows that sequence and presses Right Ctrl instead.

What it gets right:

- **Behaves like a hardware key.** Holding it repeats, using your Windows keyboard delay and repeat rate. As with a real key, pressing another key while holding it ends the repeat.
- **Combines with other modifiers.** If you are already holding Windows or Left Shift when you press the Copilot key, they stay held, so `Windows + Copilot` is `Windows + Right Ctrl`. Only the Windows and Shift presses generated by the Copilot key itself are cancelled.
- **Works with screen readers.** With the Copilot key remap option in Windows Settings, NVDA still announces the key as "windows+shift+f23". With this tool it announces "right control", because the original key sequence is swallowed and the injected keys carry correct scan codes and extended-key flags.

## Install

Download `copilot-to-right-ctrl.exe` from the releases page, or build it yourself (see below). Put it somewhere permanent, then run:

```
copilot-to-right-ctrl.exe --install
```

This starts the remapper and registers it to start when you sign in (a per-user `Run` registry entry, no administrator rights needed).

## Usage

| Command | Effect |
| --- | --- |
| `copilot-to-right-ctrl.exe` | Start the remapper for this session only. |
| `copilot-to-right-ctrl.exe --install` | Start it and register it to start at sign-in. |
| `copilot-to-right-ctrl.exe --quit` | Stop the running remapper. |
| `copilot-to-right-ctrl.exe --uninstall` | Stop it and remove the sign-in entry. |

Only one instance runs at a time; starting it again does nothing. If you move the executable, run `--install` again from the new location.

## Build

Requires the MSVC C++ build tools ("Desktop development with C++" in the Visual Studio installer).

```
build.bat
```

## Limitations

- The remapper runs without administrator rights, so Windows does not let it see keys while an elevated (administrator) window has focus. The Copilot key behaves as usual there.
- The Copilot key is recognised by timing: its Windows and Shift presses arrive within 20 ms of F23. A keyboard that sends the sequence more slowly would need the constants at the top of the source adjusted.
